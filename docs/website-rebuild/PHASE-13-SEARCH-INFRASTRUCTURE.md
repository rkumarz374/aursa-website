## 7. GOOGLE SEARCH CONSOLE STRATEGY
- **Recommended Property Type**: Domain Property (`aursa.app`)
- **Rationale**: A Domain Property covers all protocol variants (`http://`, `https://`) and root/subdomain variants (`aursa.app`, `www.aursa.app`) under a single unified GSC property without fragmenting index data.
- **Verification Method**: DNS TXT Record verification at the domain registrar / DNS provider level.
- **Verification Security**: DNS verification is preferred because it avoids injecting code/meta tags or static files into production code.

---

## 8. GOOGLE VERIFICATION STATUS
- **Status**: `USER ACTION REQUIRED`
- **Human Action Steps**:
  1. Log into Google Search Console (`search.google.com/search-console`).
  2. Click **Add Property**.
  3. Select **Domain** (left box).
  4. Enter domain: `aursa.app`.
  5. Copy the TXT record value generated by Google (e.g., `google-site-verification=...`).
  6. Open DNS provider management console for `aursa.app` and add a new `TXT` record at the root domain (`@` or `aursa.app`) with the copied value.
  7. Return to Google Search Console and click **Verify**.
  8. Do not delete the DNS TXT record after verification succeeds.

- **Monthly Review (Ongoing)**:

  - Monitor organic funnel: Search impressions -> Clicks -> Page engagement (PostHog/GA4).

---

## 21. SEARCH QUERY DECISION FRAMEWORK
- **Rule**: Organic search query data from Search Console must override speculative keyword assumptions over time.
- **Decision Logic**:
  - If GSC shows impressions for an unoptimized phrase (e.g. `AI retail trial room`), first evaluate which existing page is ranking.
  - Optimize the existing owner page (improve content depth, internal links, headings) before considering creating a new page.
  - Only create a new page if the search intent is distinctly separate from all existing hub/pillar pages.

---

## 22. GOOGLE/BING VS WEBSITE ANALYTICS MODEL
- **Search Engine Data (GSC & Bing)**: Measures **Search Discovery** (Impressions, SERP Clicks, CTR, Average Position, Crawl Status).
- **Website Analytics Data (PostHog & GA4)**: Measures **On-Site Behavior** (Pageviews, Scroll Depth, Session Duration, CTA Clicks, Conversion Funnel).
- **Integration Concept**: Treat as a connected two-stage funnel: `Search Discovery (GSC) -> On-Site Engagement & Conversion (PostHog)`.
