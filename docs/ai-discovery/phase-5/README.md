# AURSA AI Visibility Lab — Phase 5 Infrastructure

Welcome to the internal AURSA AI Visibility Lab. This directory contains the prompts, protocols, scoring rubrics, and reporting templates used to measure organic visibility across major AI assistants (ChatGPT, Claude, Gemini).

---

## Folder Structure

```
docs/ai-discovery/phase-5/
├── README.md               # Infrastructure overview & quickstart
├── benchmark-prompts.csv   # 100 Canonical Phase-1 prompts mapped to target URLs
├── results-template.csv    # Blank CSV template for benchmark runs
├── SCORING-RUBRIC.md       # Detailed scoring rules & reason codes
├── BASELINE-PROTOCOL.md    # Clean-session execution instructions
└── reports/
    └── baseline-summary.md # Analysis report generated by internal script
```

---

## Quickstart

1. Copy `results-template.csv` to `results.csv`:
   ```bash
   cp docs/ai-discovery/phase-5/results-template.csv docs/ai-discovery/phase-5/results.csv
   ```
2. Follow `BASELINE-PROTOCOL.md` to collect benchmark data.
3. Record findings in `results.csv` following `SCORING-RUBRIC.md`.
4. Run the internal analysis utility:
   ```bash
   node scripts/ai-visibility/analyze-results.mjs
   ```
5. View generated report in `docs/ai-discovery/phase-5/reports/baseline-summary.md`.
